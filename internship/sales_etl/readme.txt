# Sales Data ETL Pipeline (MySQL)
This project showsa basic ETL pipeline using a real sales dataset.

Procedure :
- Extract data from CSV
- Clean numeric and date columns
- Create derived column (profit)
- Load into MySQL
- Perform SQL analysis


Tech: Python, Pandas, MySQL

Run:
1. Execute schema.sql in MySQL
2. pip install -r requirements.txt
3. python load.py
